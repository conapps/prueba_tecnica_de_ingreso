# Documentación — Prueba técnica de ingreso

## Índice

- [**Consigna para el participante**](consigna-participante.md) — Entregar al candidato al inicio de la prueba.
- [**Guía del evaluador**](guia-evaluador.md) — Preparación del entorno, evaluación y rollback de fallas.

## Uso recomendado

1. Preparar el entorno según la [guía del evaluador](guia-evaluador.md) (secciones 2, 3 y 9).
2. Al iniciar la prueba, enviar al participante solo la [consigna](consigna-participante.md) más los accesos (servidor, Zabbix, SSH lectura, Ansible).
3. Seguir los checkpoints de comunicación indicados en la consigna entre cada parte.
