## Uso recomendado

1. Preparar el entorno según la [guía del evaluador](guia-evaluador.md) (secciones 2, 3 y 9).
2. Completar [plantilla-entrega](plantilla-entrega.md) + [plantilla-evaluador](plantilla-evaluador.md) + [`host-setup/env.prueba-tecnica`](../host-setup/env.prueba-tecnica) + [`host-setup/evaluator/cisco-credentials.env`](../host-setup/evaluator/cisco-credentials.env) (desde los `*.example`); al participante enviar consigna + plantilla de entrega.
3. Seguir los checkpoints de comunicación indicados en la consigna entre cada parte.
